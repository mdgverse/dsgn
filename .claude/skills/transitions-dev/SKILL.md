# transitions.dev (ponteiro)

A biblioteca transitions.dev tem licença própria. Ela é gratuita para uso pessoal e comercial, mas não permite redistribuição. Por isso, o código não é copiado para este repositório.

## Instalação (versão gratuita)

Pelo gerenciador de skills:

```bash
npx skills add Jakubantalik/transitions.dev
```

Ou pelo CLI da biblioteca:

```bash
npx transitions-dev add --free
```

A versão Pro exige login no navegador.

## Regras de uso

- Não redistribua a biblioteca em outros repositórios, pacotes ou produtos.
- A licença permite uso comercial. Leia os termos atuais no site da biblioteca antes de publicar.
- Se a licença mudar, revise este ponteiro antes de usar.
